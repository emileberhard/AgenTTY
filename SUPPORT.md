# Support

For setup and self-hosting, start with the [README](README.md) and
[self-hosting guide](docs/self-hosting.md).

Report reproducible bugs and feature requests through
[GitHub Issues](https://github.com/emileberhard/AgenTTY/issues). Include your
app version, iOS version, device family and a minimal reproduction. Remove
host addresses, usernames, credentials, terminal output and recordings before
sharing diagnostics.

Send account, purchase or other private support requests to
[eberhard.emil@gmail.com](mailto:eberhard.emil@gmail.com).

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/emileberhard/AgenTTY/security/advisories/new)
or the email above. Do not disclose exploitable details in public issues.

See [PRIVACY.md](PRIVACY.md) for data handling and deletion requests.
