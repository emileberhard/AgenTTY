AgenTTY is a fast, Ghostty-based SSH client for iPhone, purpose-built for power users of agentic AI coding TUIs such as Codex CLI and Claude Code.

What makes AgenTTY different from a typical iOS SSH client is that it is built around the workflows power users actually care about when running long-lived coding-agent sessions from a phone.

FEATURES

- Native iOS notifications when work finishes or an agent needs input
- Paste screenshots and images directly into supported workflows from your phone
- Persistent tmux sessions with quick reconnect
- Long-press the spacebar for a fast shell quick switcher
- Live folder and git-branch context for every shell
- A custom keyboard built for terminal work, with familiar shortcuts and modifier slide-chords
- Fast dictation for hands-free prompting on the go, with 10 minutes a month during the trial and 120 minutes a month with lifetime access

BUILT FOR LONG-RUNNING SESSIONS

AgenTTY is especially good for Codex, Claude Code, tmux, and similar terminal-native AI workflows. Keep work alive in persistent shells, jump back in when an agent needs attention, and move quickly between sessions while you are away from your desk.

NATIVE PERFORMANCE

Built on an ultra-fast Ghostty core, AgenTTY delivers native-feeling performance and smooth terminal rendering on iPhone, even during heavy output and real CLI use.

EASY HOST SETUP

Run one `npx` helper command on the host, then scan its QR code or enter the short code in the app. AgenTTY reuses or creates a device SSH key automatically, keeps the private key local on your iPhone, and finishes the setup for you.

REAL SSH ON IPHONE

Even if you do not use AI coding agents at all, AgenTTY still stands on its own as a serious SSH client. Connect to your own machines with public-key authentication, host-key verification, persistent sessions, and a terminal that feels fast, responsive, and native on iPhone.

SECURITY BY DEFAULT

Generate Ed25519 keys on-device. Private keys stay in the iOS Keychain. Host keys are pinned with trust-on-first-use protection.
